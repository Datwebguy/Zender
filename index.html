QUESTIONS

Before you get started.

What is a task account?

It is a spending authorization for one job. You choose its budget, expiry and permitted services.

When do I need to approve a purchase?

Purchases above the threshold you set require your approval. The budget and threshold include the reserved network fee.

What happens if a payment response is lost?

Zender keeps the purchase reserved and checks the recorded transaction during recovery. A retry does not create another payment.

Can I try this with test ZEC?

Yes. The current workspace uses testnet, where coins have no monetary value.

What can my agent access?

The task credential allows requests within the selected task. It does not grant the agent your owner credential or permission to change the task rules.
